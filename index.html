So spielst du auf LMS

Minecraft Java Edition · 4 einfache Schritte

01

Java Edition starten

Öffne den Minecraft Launcher und starte Minecraft: Java Edition.

02

Mehrspieler öffnen

Wähle im Minecraft-Hauptmenü den Bereich „Mehrspieler“.

03

Server hinzufügen

Klicke auf „Server hinzufügen“ und trage die LMS Server-Adresse ein.

LMS_server.aternos.me
04

Spielen

Server speichern, LMS auswählen und auf „Server beitreten“ klicken.

Wichtig: LMS ist für Minecraft Java Edition gedacht. Die Server-IP lautet LMS_server.aternos.me.
