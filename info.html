Minecraft Versionen

LMS SERVER unterstützt Minecraft Java Edition.

Wir unterstützen die neuesten Minecraft Versionen.

Bitte nutze immer eine aktuelle Version, damit du die beste Erfahrung bekommst.

Forge, NeoForge & Fabric

Du kannst mit verschiedenen Mod-Loadern auf dem LMS SERVER spielen.

Unterstützt:

Forge
NeoForge
Fabric

Wichtig:

Mods, die nur für deinen eigenen Client sind, können verwendet werden.

Mods, die auf dem Server installiert sein müssen, werden nicht unterstützt.

Mods

Erlaubt sind zum Beispiel:

Performance-Mods
Grafik-Mods
Client-Erweiterungen

Nicht unterstützt werden Mods, die neue Inhalte oder Funktionen auf dem Server benötigen.

Optifine Informationen
