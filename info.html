Minecraft Versionen

Der LMS SERVER läuft auf der Minecraft Java Edition.

Unterstützte Version:

Minecraft 1.21.x

Wir empfehlen immer die aktuellste Version, damit du alle Funktionen nutzen kannst.

Mods

Auf dem LMS SERVER sind bestimmte Client-Mods erlaubt.

Erlaubt:

✔ Performance-Mods
✔ Grafik-Mods
✔ Optimierungs-Mods
✔ Client-Erweiterungen

Nicht erlaubt:

✘ Cheats
✘ Vorteile gegenüber anderen Spielern
✘ Mods, die Serverfunktionen benötigen

Forge

Forge ist ein bekannter Minecraft Mod-Loader.

Client-Mods ohne Serverinstallation können genutzt werden.

Fabric

Fabric ist ein leichter Mod-Loader.

Viele Performance-Mods nutzen Fabric.

NeoForge

NeoForge ist eine Weiterentwicklung von Forge.

Es gelten die normalen LMS SERVER Regeln.

Optifine

Optifine kann auf dem LMS SERVER verwendet werden.

Mit Optifine kannst du:

• Grafik verbessern
• FPS erhöhen
• Shader nutzen
• Einstellungen optimieren
