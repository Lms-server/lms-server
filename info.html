Minecraft Versionen

Der LMS SERVER läuft auf der Minecraft Java Edition.

Unterstützte Versionen:

Minecraft 1.21.x

Wir empfehlen immer die aktuellste Version zu verwenden, damit du alle Funktionen nutzen kannst.

Mods

Auf dem LMS SERVER sind bestimmte Client-Mods erlaubt.

Erlaubt:

✔ Performance-Mods
✔ Grafik-Mods
✔ Optimierungs-Mods
✔ Client-Erweiterungen

Nicht erlaubt:

✘ Mods, die neue Server-Funktionen hinzufügen
✘ Cheats oder Vorteile gegenüber anderen Spielern
✘ Programme, die den Spielablauf verändern

Optifine

Optifine kann auf dem LMS SERVER verwendet werden.

Mit Optifine kannst du:

• Grafik verbessern
• FPS erhöhen
• Shader nutzen
• Einstellungen optimieren

Forge

Forge ist einer der bekanntesten Mod-Loader für Minecraft.

Auf dem LMS SERVER können Client-Mods genutzt werden, die keine Serverinstallation benötigen.

Fabric

Fabric ist ein leichter und schneller Mod-Loader.

Viele Performance-Mods verwenden Fabric.

NeoForge

NeoForge ist eine Weiterentwicklung von Forge.

Auch hier gelten die normalen LMS SERVER Regeln für Mods.
